# 📦 Parcel Tracking App

配送番号を入力するだけで、各配送業者の追跡ページへワンクリックでアクセスできる Web アプリケーションです。

## 機能

- **11 配送業者対応** — 佐川急便 / ヤマト運輸 / 西濃運輸 / 福山通運 / オカケン / DHL / FedEx / OCS / YDH / SF Express / 日本郵便
- **自動業者検出** — 配送番号の形式から入力中に配送業者を自動判定（日本郵便のJP形式・SF ExpressのSF形式・FedExのDoor Tag形式のみ一意に判定。数字のみは手動選択）
- **2 つの確認モード**
  - **📡 ステータス確認** — Cloudflare Worker 経由で配送状況を取得（別途 Worker デプロイが必要）
  - **URL 表示** — 「共有用にコピーする」として詳細情報・業者名・追跡番号・URL を表示しワンクリックでコピー
- **荷物区分トグル** — 📤 発送 / 📥 受取 の切り替え。保存済みリストでも色分け表示
- **詳細フィールド（任意）** — 指定日・時間帯 / サイズ / 個口数 を入力可能。URL 表示時に `|` 区切りで表示
- **2 種類のコピー** — 「URLをコピー」「テキスト全体をコピー」（詳細情報 + URL をワンラインでコピー）
- **入力バリデーション** — 業者ごとに適切な桁数・形式をチェック
- **履歴保存** — 確認した追跡番号を LocalStorage に保存（最大 8 件）。クリックで再アクセス、✕ で削除
- **ハイフン自動除去** — 入力されたハイフンは自動で取り除かれます
- **メモ機能** — 各追跡番号に任意のメモ（品番・発送先など）を添えて保存
- **モバイル対応** — レスポンシブレイアウト・44px タッチターゲット・iOS ズーム防止

## 対応配送業者

| 業者 | 識別子 | 形式 | 自動検出 |
|------|--------|------|:--------:|
| 🚚 佐川急便 | `sagawa` | 数字 10 桁または12桁 | — |
| 🐈 ヤマト運輸 | `yamato` | 数字 11 桁または12桁 | — |
| 🦘 西濃運輸 | `seino` | 数字 10 桁または12桁 | — |
| 🌅 福山通運 | `fukutsu` | 数字 10 桁または11桁 | — |
| 🦺 オカケン | `okaken` | 数字 10 桁 | — |
| 🛩️ DHL | `dhl` | 数字 10 桁 | — |
| ✈️ FedEx | `fedex` | 数字 10・12・15・20・22桁 / `DT` + 数字12桁 | ✅（DT形式のみ） |
| 🌐 OCS | `ocs` | 数字 11〜12桁 | — |
| 🐼 YDH | `ydh` | 英数字 10〜40文字（固定桁なし） | — |
| 🇨🇳 SF Express | `sfexpress` | `SF` \+ 数字 13 桁 / 数字 12 桁 | ✅ |
| 🏣 日本郵便 | `japanpost` | `XX000000000JP` / 数字 11 桁 | ✅ |

> 数字だけの番号は複数業者の形式と競合するため、自動検出せず手動選択にします。`XX000000000JP`、`SF` + 数字13桁、`DT` + 数字12桁のように一意な形式だけ自動検出します。

## 使い方

1. **荷物区分を選択** — 📤 発送 または 📥 受取
2. **配送業者を選択** — ボタンをクリック
3. **配送番号を入力** — ハイフン込みでも OK（自動検出対応の業者は自動選択）
4. **メモを入力（任意）** — 品番や発送先など
5. **詳細フィールドを入力（任意）** — 指定日・時間帯 / サイズ / 個口数
6. **確認モードを選択**
   - `📡` → ステータス情報を画面に表示（Worker 要デプロイ・初期状態）
   - `URL` → 「共有用にコピーする」を表示して詳細情報付き URL をコピー
7. **「配送状況を確認」をクリック**

### URL 表示のフォーマット

```
佐川急便 | 6/25 午前 | 80サイズ | 2個口 | お問合せNo. 123456789012
https://k2k.sagawa-exp.co.jp/p/web/okurijosearch.do?okurijoNo=123456789012
```

- 並び順: 運送業者 | 着指定日 | サイズ | 個口 | 問い合わせ番号
- サイズ・個口数は数字のみ入力可能（自動で「サイズ」「個口」の接尾辞が付与）
- 空欄のフィールドは自動的に省略されます
- 発送/受取の区分は保存済みリストにのみ表示（URL表示には含まない）

### 保存済みリストの色分け

| 区分 | アイコン | 左ボーダー色 |
|------|---------|-------------|
| 発送 | 📤 | 🟠 オレンジ |
| 受取 | 📥 | 🔵 ブルー |

## 開発

### 必要条件

- [Bun](https://bun.sh/)（ランタイム・パッケージ管理）

### セットアップ

```bash
bun install
```

開発用ローカルサーバー:

```bash
bun run dev
```

本番ビルドとプレビュー:

```bash
bun run build
bun run preview
```

### Cloudflare Worker のデプロイ

`📡 確認` モードを使用するには、Cloudflare Worker のデプロイが必要です。

```bash
cd workers
bunx wrangler deploy
```

現在の `scraper.js` にはデプロイ済み Worker URL が設定されています。別環境へデプロイする場合だけ、`WORKER_URL` をその環境のURLへ変更してください。

#### ステータス取得対応状況

| 業者 | Worker 経由ステータス取得 |
|------|:-----------------------:|
| 日本郵便 | ✅ HTML パース |
| 佐川急便 | ✅ HTML パース |
| オカケン | ✅ HTML パース |
| OCS | ✅ 結果テーブルのHTMLパース |
| その他 | ⚠️ 照会は実行するが、自動判定は未対応 |

> ヤマト運輸・DHLはセッション認証、SF ExpressはSPAのため、WorkerのHTMLパースではヒット判定できません。未対応業者は `unavailable` に分類し、ヒット一覧には表示しません。

#### 全業者照会API

`GET /?number={追跡番号}` で `carrier.js` に登録された全業者へ並列照会します。

```json
{
  "number": "123456789012",
  "hits": [],
  "checked": ["sagawa", "yamato", "..."],
  "unavailable": [{ "carrier": "sfexpress", "message": "..." }],
  "errors": []
}
```

`hits` に入るのは、HTMLパーサーが追跡情報を確認できた業者だけです。`?carrier=sagawa&number=...` の従来の単一業者照会も引き続き利用できます。
